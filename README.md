# Manager Bonus Tracker

Weekly tracker for store managers' quarterly bonus criteria (sales, transactions, food cost & counts, labor, fan feedback, deliveries, truck counts, drive-thru).

- Open the site link, set up your store once, then add your numbers every Thursday.
- **Your data is stored only in your own browser on your own device.** Nothing is sent to GitHub or any server.
- Tap **Backup** monthly and keep the .json file safe. **Restore** brings it back on a new phone or computer.
- On iPhone: Safari → Share → **Add to Home Screen**. On Android: Chrome → ⋮ → **Add to Home screen**.

Projected payouts are estimates; the owner's payout sheet is final.
