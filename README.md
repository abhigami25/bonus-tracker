# Performance Tracker — Dairy Queen

Weekly performance and quarterly bonus tracker for Dairy Queen store managers (general, operations and assistant managers). Internal tool — not an official Dairy Queen product.

## Screens
- **All stores** — for the general/operations manager: bonus on track across stores, biggest opportunities, store scorecard (8 bonus criteria), latest week per store.
- **Store detail** — one store: projected GM/AM bonus, where to focus, criteria status, Thursday entry, week-by-week history and charts, monthly roll-up.
- **Setup** — set once: your name/role, stores (labor goal, treat store, EcoSure, AM certs), bonus goals. Backup / Restore / CSV.

## Your data
- Stored **only in your own browser on your own device**. Nothing is sent to GitHub or any server.
- Clearing browser data or using private mode erases it. Tap **Backup** monthly and keep the .json file safe; **Restore** brings it back on a new device.
- iPhone: Safari → Share → **Add to Home Screen**. Android: Chrome → ⋮ → **Add to Home screen**.

Bonus figures are estimates; the owner's payout sheet is final.
